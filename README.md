# Долги — Vercel + Supabase

Личный учёт долгов на Next.js. Интерфейс и серверные API работают на Vercel; существующие данные и авторизация остаются в Supabase. Авторизация ChatGPT и Cloudflare для этой версии не требуются.

## Развёртывание

1. Подключите этот репозиторий в Vercel или обновите существующий проект.
2. Root Directory: корень репозитория (`.` / пустое поле). Framework Preset: Next.js. Удалите старые переопределения Output Directory. Настройки сборки и установки заданы в `vercel.json`.
3. Добавьте серверную переменную `DOLGI_ALLOWED_EMAILS` с подтверждённым email вашего аккаунта Supabase. Для нескольких разрешённых аккаунтов используйте запятую. Без неё доступ к данным закрыт. Не добавляйте префикс NEXT_PUBLIC и не коммитьте личный email.
4. Запустите деплой. Откройте его адрес и войдите тем же аккаунтом, которым пользовались раньше.
5. Для GitHub OAuth добавьте точный HTTPS-адрес Vercel в Supabase → Authentication → URL Configuration → Redirect URLs. Установите корректный Site URL для ссылок подтверждения email. Вход по паролю не требует GitHub OAuth.

`lib/supabase-config.ts` содержит только публичный адрес и publishable key прежнего проекта. Ключ service_role для приложения не нужен. Перед эксплуатацией убедитесь, что миграции `supabase/migrations` уже применены, RLS включён и правила доступа проверены в работающей базе. Не запускайте миграции повторно вслепую.

## Данные и безопасность

- Запросы API проверяют аккаунт через Supabase Auth и разрешённый email. Переданные клиентом заголовки ChatGPT не используются для авторизации.
- Access/refresh tokens хранятся в HttpOnly cookies; в production используется Secure. Ответы с данными не кешируются; POST проверяет origin.
- PIN и его серверные проверки приложения сохранены. При этом права Supabase позволяют владельцу действующей сессии обращаться к своим данным напрямую: PIN не является независимым вторым фактором.
- Сеанс аккаунта сохраняется между открытиями. PIN, если установлен, блокирует приложение после сворачивания или 15 минут без действий. Полный серверный выход по бездействию без PIN в этой версии не реализован.
- Серверный список email ограничивает этот сайт, но не заменяет RLS в Supabase.
- Данные, уже перенесённые в Supabase, доступны под прежним аккаунтом. Автоматический перенос из старой Cloudflare D1 на Vercel недоступен. Если записи остались только в D1, экспортируйте резервную копию в старом приложении и восстановите её через настройки нового. Восстановление заменяет текущий учёт: сначала сохраните его копию.

## Локальная проверка

Node.js 24, pnpm. Создайте `.env.local` по `.env.example`.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
pnpm test
```

Публикация исходников не публикует данные базы. Не добавляйте `.env`, выгрузки долгов или приватные ключи в Git.
